# Node.js Adapter Note

AI-HPP does not require Node.js, and this directory is not a reference runtime
implementation.

A Node.js implementation may use the language-neutral
[implementation starter](../README.md) and load the shared
[MVP negative test vectors](../mvp-negative-test-vectors.json). Its local
modules and APIs remain implementation choices. Repository tooling checks
document and data consistency only; it does not prove runtime conformance.
