# Python Adapter Note

AI-HPP does not require Python, and this directory is not a reference runtime
implementation.

A Python implementation may use the language-neutral
[implementation starter](../README.md) and load the shared
[MVP negative test vectors](../mvp-negative-test-vectors.json). Its local
classes and APIs remain implementation choices. Repository Python scripts check
document and data consistency only; they do not prove runtime conformance.
